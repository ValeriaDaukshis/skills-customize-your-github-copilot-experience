# 📘 Assignment: REST APIs with FastAPI

## 🎯 Objective

Build a REST API using Python and the FastAPI framework. Students will create endpoints, handle JSON requests and responses, and practice defining data models with Pydantic.

## 📝 Tasks

### 🛠️ Create the API service

#### Description
Implement a FastAPI application that exposes multiple routes for working with items. The application should accept JSON input, return structured JSON output, and use request validation to ensure data is correct.

#### Requirements
Completed assignment should:

- Define a FastAPI application with at least three routes
- Use Pydantic models for request body validation
- Return JSON responses for GET and POST requests
- Provide a response when an item is not found
- Include clear route names and endpoint behavior
